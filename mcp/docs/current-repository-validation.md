## 验证结论与改进项

本次真实运行证明服务能够在当前仓库中构建知识/代码统一图谱，并以结构化节点、相对路径和行号返回可追溯结果。`search_knowledge` 对 Markdown 文档主题与分段内容的结合检索已经可用；Python 仍可通过 `kinds=["function", "method"]` 进行精确符号检索。

当前检索器是确定性词项评分，并非语义向量或语言模型重排器。因此，“PostgreSQL”这类在多个章节出现的词会召回正确但不一定最窄的章节；这正是后续路线图中“字段化知识卡、BM25/向量混合召回、可选重排与离线评测集”的优先改进对象。`shares_terms` 边也属于弱关联，只能作为探索线索，不能替代来源引用或人工判断。
