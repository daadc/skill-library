# ADR-0002：采用本地 SQLite 快照、显式刷新与可选只读知识工作台

| 字段 | 内容 |
|---|---|
| 状态 | `accepted`（本地 R1/R2 范围） |
| 日期 | 2026-08-25 |
| Owner | 用户（功能与发布决定） |
| 关联 ADR | ADR-0001 |
| 复审触发器 | 多仓库共享、远程监听、多人认证、写入知识资产、索引规模/延迟无法满足本地 SQLite，或新增网络工具。 |

## 决定

在当前只读 MCP 内核之上，增加一个**本地 SQLite 状态库**，保存图谱快照、文件指纹、构建元数据和 FTS5 全文索引。刷新仍由 CLI、MCP 或工作台用户**显式触发**；服务不得启动后台 watcher、不得自动写入被索引仓库、不得执行源代码，也不得默认打开网络端口。

P0 CLI、P1 持久化索引和 P2 工作台共用同一个 `KnowledgeConnectionService`。CLI 的查询命令和工作台 API 都必须先加载或显式刷新本地快照；MCP 工具保持只读，并新增 `index_status` 和 `refresh_repository` 的窄化查询/刷新能力。SQLite 状态默认存放在受控的 `.knowledge-connection/` 目录，且该目录必须位于允许根目录之内；该目录只包含服务自身的可再生成数据。

工作台以 `127.0.0.1` 的本地 HTTP 服务器提供静态 HTML、CSS 和 JavaScript，并只公开与现有只读查询相同的有限 API。它默认不监听局域网或公网、不接受任意路径、shell、URL、SQL 或代码执行参数。写操作、用户认证、远程访问和协作治理不属于本次实现。

## 信任边界与控制

| 边界 | 输入/风险 | 确定性控制 |
|---|---|---|
| CLI 与 MCP 参数 | 路径穿越、超限、错误类型、查询注入。 | 根目录解析、扩展名白名单、深度/数量/字符上限、稳定错误码。 |
| 被索引文件 | 不可信内容、提示注入、恶意大文件、符号链接。 | 仅解析常规非符号链接文件；内容只作为数据；大小/文件数限制；不执行文本。 |
| SQLite 状态 | 损坏、旧版本、敏感内容残留。 | 参数化 SQL、schema 版本、原子事务、状态目录限定、可删除并重建。 |
| 工作台 HTTP | 非本机访问、跨源滥用、API 参数绕过。 | 强制 loopback bind、相同根目录策略、无凭据/API key、仅 GET/受限 POST、禁止远程 host。 |
| 图谱关系 | 弱词项关系被误解为证据。 | `shares_terms` 保留理由并在 UI 标为弱关联；引用和文件定位优先显示。 |

## 备选方案

| 方案 | 结论 | 原因 |
|---|---|---|
| 仅内存图 + MCP | 不采用。 | 缺少可脚本化 CLI、刷新状态、评测复现和工作台数据源。 |
| 远程数据库与 SaaS 工作台 | 不采用。 | 当前没有多用户、远程协作或数据出境需求，会扩大授权和运行风险。 |
| SQLite + 本地 loopback 工作台 | 采用。 | 零外部服务、Python 标准库可用、可删除重建，满足当前 P0-P2 最小范围。 |
| 全面 Graph DB/向量平台 | 延后。 | 需要真实规模和检索评测证据，不能以架构预设代替需求。 |

## 验收与停止条件

实现必须证明：持久化后的图谱可重新加载；未变更工作树可命中缓存；变更后刷新生成新快照且旧快照不被破坏；CLI、MCP 与工作台对相同查询得到一致类型的结果；工作台不能绑定非 loopback host；根目录外路径、符号链接、SQL/命令类参数和写入接口均不存在或被拒绝。任何新增写操作、远程访问、用户身份或网络出口，必须停止并建立新的 ADR、契约和人工审批。
